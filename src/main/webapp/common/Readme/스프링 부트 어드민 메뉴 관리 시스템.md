# 스프링 부트 어드민 메뉴 관리 시스템

JPA를 사용한 계층형 메뉴 관리 시스템입니다.

## 주요 기능

- 3단계 계층형 메뉴 구조 지원
- 드래그 없이 부모-자식 관계 설정
- 메뉴 순서 관리
- 아이콘 클래스 지정
- 사용 여부 관리
- Ajax 기반 실시간 업데이트

## 기술 스택

- Spring Boot 2.7.14
- Spring Data JPA
- MySQL 8.0
- JSP/JSTL
- jQuery 3.6.0
- Bootstrap 5.1.3
- Font Awesome 4.7.0

## 설치 방법

### 1. 데이터베이스 설정

```sql
-- 데이터베이스 생성
CREATE DATABASE admin_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- init_admin_menu.sql 파일 실행
mysql -u root -p admin_db < init_admin_menu.sql
```

### 2. application.yml 설정

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/admin_db
    username: your_username
    password: your_password
```

### 3. 프로젝트 빌드 및 실행

```bash
mvn clean install
mvn spring-boot:run
```

### 4. 접속

```
http://localhost:8080/admin/menu/list
```

## 데이터베이스 스키마

```sql
CREATE TABLE ADMIN_MENU (
    menu_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    parent_id BIGINT NULL,
    menu_name VARCHAR(100) NOT NULL,
    menu_url VARCHAR(255) NULL,
    menu_order INT NOT NULL DEFAULT 1,
    menu_level INT NOT NULL DEFAULT 1,
    use_yn CHAR(1) NOT NULL DEFAULT 'Y',
    icon_class VARCHAR(100) NULL,
    FOREIGN KEY (parent_id) REFERENCES ADMIN_MENU(menu_id)
);
```

## API 엔드포인트

### 메뉴 관리 화면
- `GET /admin/menu/list` - 메뉴 관리 화면

### Ajax API
- `GET /admin/menu/tree` - 트리 구조 메뉴 조회
- `GET /admin/menu/all` - 전체 메뉴 목록 조회
- `GET /admin/menu/{menuId}` - 특정 메뉴 상세 조회
- `GET /admin/menu/parent-list` - 부모 메뉴 목록 조회
- `POST /admin/menu/save` - 메뉴 저장 (신규/수정)
- `DELETE /admin/menu/{menuId}` - 메뉴 삭제

## 사용 방법

### 1. 메뉴 추가
1. "신규" 버튼 클릭
2. 메뉴 정보 입력
   - 메뉴명 (필수)
   - 메뉴 URL
   - 상위 메뉴 선택 (최상위는 선택 안함)
   - 아이콘 클래스
   - 메뉴 레벨 (자동 설정됨)
   - 정렬 순서
   - 사용 여부
3. "저장" 버튼 클릭

### 2. 메뉴 수정
1. 왼쪽 메뉴 트리에서 수정할 메뉴 클릭
2. 오른쪽 폼에서 정보 수정
3. "저장" 버튼 클릭

### 3. 메뉴 삭제
1. 왼쪽 메뉴 트리에서 삭제할 메뉴 클릭
2. "삭제" 버튼 클릭
3. 확인 다이얼로그에서 확인

### 4. 메뉴 구조 예시

```
Dashboard (1단계)
시스템 관리 (1단계)
  ├─ 메뉴 관리 (2단계)
  ├─ 코드 관리 (2단계)
  └─ 권한 관리 (2단계)
사용자 관리 (1단계)
  ├─ 사용자 목록 (2단계)
  ├─ 그룹 관리 (2단계)
  └─ 접속 이력 (2단계)
콘텐츠 관리 (1단계)
  ├─ 게시판 관리 (2단계)
  │   ├─ 게시글 관리 (3단계)
  │   ├─ 댓글 관리 (3단계)
  │   └─ 카테고리 관리 (3단계)
  ├─ 공지사항 (2단계)
  └─ FAQ 관리 (2단계)
```

## 주요 특징

### 1. 계층형 구조
- 최대 3단계까지 메뉴 구성 가능
- 부모-자식 관계 자동 관리
- 트리 구조 시각화

### 2. 자동 레벨 설정
- 부모 메뉴 선택 시 자동으로 레벨 설정
- 최상위 메뉴는 레벨 1
- 하위 메뉴는 부모 레벨 + 1

### 3. 정렬 기능
- menu_order 필드로 메뉴 순서 관리
- 같은 레벨 내에서 순서 조정 가능

### 4. 아이콘 지원
- Font Awesome 아이콘 사용
- 커스텀 아이콘 클래스 지정 가능

### 5. 사용 여부 관리
- use_yn 플래그로 활성/비활성 관리
- 비활성 메뉴는 화면에 표시되지 않음

## 트러블슈팅

### 1. JSP 파일을 찾을 수 없는 경우
```yaml
spring:
  mvc:
    view:
      prefix: /WEB-INF/views/
      suffix: .jsp
```

### 2. JPA 매핑 오류
- Entity 클래스의 @Table 어노테이션 확인
- 데이터베이스 테이블 이름과 일치하는지 확인

### 3. 외래키 제약조건 오류
- 자식 메뉴가 있는 부모 메뉴는 삭제 불가
- CASCADE 옵션으로 자동 삭제 설정됨

### 4. Ajax 요청 실패
- 브라우저 개발자 도구 콘솔 확인
- 서버 로그 확인
- URL 매핑 확인
